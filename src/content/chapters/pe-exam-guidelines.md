## 1. Before Exam Day

- Check for and install the latest version of the exam software.
- Verify that your NetBeans and JDK versions match what the exam requires.

The tools you are allowed to use are:

- NetBeans 8.x or newer.
- JDK 1.8 – Java 8.
- Notepad.
- Command Prompt.
- WinRAR or WinZip.
- Windows Explorer – File Explorer.

You may only open and use the tools listed above. Opening any other application — even by mistake, or without actually using it — can still be treated as a rule violation and may result in a 0 for the PE.

- Bring your ID card (CCCD) or VNeID so the invigilator can check it before you enter the exam room.
- You may prepare scratch paper for notes and to break down the problem statement.
- Make sure you remember your exam software login credentials exactly.
- Try opening NetBeans, creating a project, and running a simple Java program beforehand to confirm your JDK works properly.

## 2. Preparing Your Exam Folder

Create a short, unaccented, single-word folder name ahead of time to avoid path-related errors, for example:

```
D:\PE_PRO192
```

Inside it, you can organize subfolders such as:

- A folder for the exam software installer (PEA_Client).
- A folder for reference code.
- A folder to save the exam-day materials you download.

During the exam, save all materials into this prepared folder to avoid:

- Not being able to find a file.
- Editing the wrong project.
- Submitting the wrong file or the wrong version.
- Wasting time searching for files.

## 3. Before the Exam Starts

- Arrive 10–15 minutes earlier than the scheduled time (so the invigilator can call you in earlier if possible, giving you more time to set up your machine).
- Turn off your VPN.
- Turn off antivirus software or other third-party security apps that might block the exam software.
- Close any applications you're not allowed to use (open Task Manager with Ctrl + Shift + Esc to check).
- Pay special attention to apps that can auto-launch via a keyboard shortcut, such as Copilot.
- Forget the Wi-Fi Student network's password, or disable auto-connect, so your machine doesn't switch networks mid-exam.
- During the exam, you must be connected to the Wi-Fi Exam network. This network has no internet access and is used only to reach the exam software.

## 4. When the Exam Paper Opens

- Download the materials into the folder you prepared.
- Skim through the entire exam paper before you start coding.
- Do not rename any project, package, class, method, or file provided by the exam paper.

While reading the exam paper, pay close attention to:

- The method name and its return type.
- The list of parameters.
- Any filtering or sorting conditions.
- Whether the order should be ascending or descending.
- Whether the result is case-sensitive.
- Whether the paper asks you to `return` the result or print it to the console.
- The provided test cases — study them carefully to understand the expected input/output.

## 5. During the Exam

- Prioritize the questions you're confident you can solve.
- Finish each question completely — verify the result and submit it — before moving to the next one.
- If you don't know how to approach a question right away, skip it temporarily and work on another one first.
- Don't spend too much time on one hard question while easier ones remain unfinished.

PE exams are typically graded based on output results and test cases. Incomplete or partially correct code may receive no credit at all. So finishing fewer questions completely and correctly is better than leaving many questions half-done.

After finishing each question:

- Clean and Build the project.
- Run the program to test it.
- Compare the result against the sample output.
- Test a few additional cases of your own.
- Submit the correct file as required (submission instructions are usually at the start of the exam paper).
- Confirm the exam software has registered your submission successfully.

**Finally, before you leave, remember to sign in on the school's e360 website.**
