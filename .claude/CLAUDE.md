## Tổng quan dự án pro192web

**Là gì:** Nền tảng học Lập trình Hướng đối tượng (OOP) bằng Java — môn PRO192 tại Đại học FPT. Do MST Software xây dựng, là bản rebuild bằng React của trang tài liệu tĩnh cũ (pro192web.netlify.app). Production: https://pro192web.chunhau-py-015.workers.dev/

**Tầm nhìn:** Không chỉ là làm mới UI — mục tiêu dài hạn là biến thành một learning platform có thể mở rộng (tìm kiếm thật, có thể sau này có quiz/exercise...), không dừng ở nội dung tĩnh.

**Nội dung:** 11 chương bám sát syllabus PRO192 chính thức: Chào mừng → Introduction Course → Nền tảng → Đóng gói → Kế thừa → Đa hình → Mảng đối tượng → Bộ sưu tập (Collections) → Bộ nhớ động → Xử lý ngoại lệ → Nhập xuất tệp (File IO). Song ngữ Việt (mặc định) / English. Từ 2026-07-25 có thêm 2 chương bổ sung ngoài syllabus chính thức, KHÔNG xuất hiện trong lưới 11 chương marketing ở Landing (`src/data/chapters.ts` cố ý giữ nguyên 11, xem mục LandingPage bên dưới): **"Trừu tượng"** (`abstraction`, nhóm "Lập trình hướng đối tượng", đặt sau Đa hình — do giáo viên chưa gửi tài liệu chuẩn, nội dung Abstract class/Interface/default/static method do Claude soạn dựa theo văn phong các chương OOP hiện có, cần giáo viên xác nhận lại khi có tài liệu chính thức) và **"Lưu ý khi thi PE"** (`pe-exam-guidelines`, nhóm riêng "Kỳ thi PE" ở cuối — checklist/kinh nghiệm thi thực hành PE). Tổng cộng hiện có 13 chương trong hệ thống nội dung (`chapters.length`, không hardcode số).

### Tech stack (đã khoá — không đổi nếu không được yêu cầu rõ)
React 19 + TypeScript 6 + Vite 8 · React Router DOM v7 (SPA client-side) · Tailwind CSS v4 (CSS-first config, KHÔNG có `tailwind.config.js`) · Motion (Framer Motion v12) · react-markdown + remark-gfm · prism-react-renderer (Java syntax highlight) · Deploy Cloudflare Workers qua wrangler v4 · Lint bằng oxlint (KHÔNG dùng ESLint) · Husky pre-commit chạy oxlint · Vitest (unit test cho logic thuần, không test component) · Fuse.js (fuzzy search cho Docs)

### Kiến trúc
- **Routing** (`src/router/AppRouter.tsx`): tất cả route lazy-load. `/` → `LandingPage` (marketing) · `/docs/:slug` → `DocsPage` bên trong `DocsLayout` (3 cột: Sidebar trái · nội dung giữa · TableOfContents phải). `LanguageProvider` bọc toàn bộ app. Không còn trang Syllabus nội bộ (`/syllabus-pro192-spring2021`) — đã xoá theo yêu cầu user (2026-07-25); mọi link "Syllabus/Đề cương môn học" (chương Welcome, `DocsFooter.tsx`, `SiteFooter.tsx`) trỏ thẳng ra trang syllabus chuẩn của trường: `https://flm.fpt.edu.vn/gui/tool/AllPrequisiteSubject?educationLevel=fptu`.
- **Hệ thống nội dung**: Chapter là data thuần (`src/content/chapters/index.ts` + `types.ts`), nội dung markdown nạp từ file `.md`/`.vi.md` cạnh nhau qua `import.meta.glob(..., { eager: true })` — bundle lúc build, không fetch runtime. `bodyVi` fallback về `body` (tiếng Anh) kèm thông báo "đang cập nhật bản dịch" khi thiếu.
- **`docs/content/*/content.md` + `docs/images/`**: nội dung SCRAPE từ site cũ — chỉ để tham khảo khi viết nội dung thật vào `src/content/chapters/*.md`, KHÔNG được build/bundle vào app.
- **Render markdown** (`src/components/MarkdownContent.tsx`): custom component mapping cho react-markdown — heading tự sinh slug (phục vụ TOC), ảnh fallback về khung placeholder khi 404, code block qua `CodeBlock` (prism-react-renderer, luôn nền tối bất kể theme), blockquote có style riêng (vàng/xanh) dựa trên match text cụ thể trong nội dung — hơi fragile, cẩn thận khi sửa nội dung liên quan.
- **Theme**: token ngữ nghĩa CSS-first trong `src/index.css` (`--canvas`, `--ink`, `--hairline`...), đổi giá trị qua class `.dark`. `useTheme` hook quản lý light/dark/system, lưu localStorage, tự theo dõi đổi theme hệ điều hành khi ở chế độ system. Dark mode dùng tông đen-xanh (navy, `--canvas: #080b14`) thống nhất cho cả Docs lẫn Landing (đổi từ đen trung tính trước đây). Landing page giờ theme-aware đầy đủ (dùng chung `useTheme()`), light mode có nền gradient xanh nhạt + hiệu ứng glow riêng — token riêng nằm ở `src/styles/landing.css` (`--landing-*`, chỉ giữ những gì thật sự khác site: bề mặt kính mờ, panel code viewer, gradient/glow nền), còn màu chữ/border/accent dùng chung token của site (`text-ink`, `border-hairline-strong`, `bg-accent`...).
- **Ngôn ngữ**: `useLanguage` hook (Context + localStorage, mặc định `vi`), tách biệt với theme vì cần re-render nội dung.
- **Quiz cuối chương**: `QuizSection`/`QuizQuestion` (`src/components/quiz/`) render ở cuối `DocsPage.tsx`. Kho câu hỏi mỗi chương là 1 file `src/content/quizzes/<slug>.ts` (giống quy ước `.md` của `src/content/chapters`), nạp qua `getQuizPool()`. Mỗi lần vào trang bốc ngẫu nhiên cố định 5 câu (`pickQuestions` trong `src/lib/quiz.ts`, có unit test). Điểm lần gần nhất lưu localStorage (`pro192-quiz-<slug>`). Đã có kho câu hỏi thật (6 câu/chương, song ngữ) cho 10 chương: `foundations`, `encapsulation`, `inheritance`, `polymorphism`, `abstraction`, `array-of-objects`, `collections`, `dynamic-memory`, `exception-handling`, `file-io`. Có chủ đích KHÔNG làm quiz cho `welcome`, `introduction-course` và `pe-exam-guidelines` (nội dung không phải khái niệm OOP). `QuizSection` tự ẩn khi kho rỗng.
- **Search trong Docs** (`⌘K`/`Ctrl+K`): `SearchModal` (render qua `createPortal` vào `document.body` để tránh bị containing-block của `backdrop-blur` trên `<header>` cắt overlay) mở từ `DocsHeader.tsx`, tìm trên index dựng runtime từ `chapters` (`src/lib/search-index.ts`, có unit test) — index gồm 3 loại entry: tiêu đề chương, heading H2/H3 (qua `extractHeadings()`, dùng cho TOC), và **nội dung thân bài** (đoạn văn/bullet/heading H4 trở xuống, quét dòng-theo-dòng, gắn với heading H2/H3 gần nhất làm anchor điều hướng — heading H4+ không có anchor riêng nên trỏ về heading cha). So khớp mờ qua Fuse.js (3 key có trọng số khác nhau), bỏ dấu tiếng Việt khi so khớp (`stripDiacritics`). Chỉ tìm trong ngôn ngữ đang hiển thị. Cùng một `SearchModal` được dùng ở cả khu vực Docs (`DocsHeader.tsx`) lẫn Landing (`LandingNav.tsx`, nút "Search... ⌘K"), mỗi nơi tự quản lý state `searchOpen` + gọi `useSearchShortcut` riêng. Kết quả trỏ tới `/docs/<slug>#<headingId>` — `DocsLayout.tsx` đã sửa để cuộn tới đúng heading thay vì luôn cuộn lên đầu khi URL có `#hash`. 5 kết quả đã bấm gần nhất lưu localStorage (`pro192-recent-searches`).
- **Slug chương — tiếng Anh**: slug định danh chương (dùng cho URL `/docs/<slug>`, tên file `.md`/`.vi.md`, thư mục `public/images/<slug>/`, file `src/content/quizzes/<slug>.ts`) đã đổi từ tiếng Việt sang tiếng Anh (vd `dong-goi` → `encapsulation`, `ke-thua` → `inheritance`) — chỉ đổi slug/tên file, tiêu đề/mô tả hiển thị (`title`, `description`) vẫn giữ tiếng Việt. URL tiếng Việt cũ tự động redirect sang slug mới qua `src/content/legacy-slugs.ts` (`LEGACY_SLUG_REDIRECTS`) + `Navigate` trong `DocsPage.tsx`. Thư mục tham khảo `docs/content/`, `docs/screenshots/`, `docs/images/` cũng đã đổi tên đồng bộ theo slug mới.
- **Tải tài liệu PDF**: nút tải `public/downloads/pro192-course-pdfs.zip` (11 file PDF, một cho mỗi chương, chỉ tiếng Anh) xuất hiện ở 2 nơi — card lớn (icon "chồng giấy" CSS thuần) ngay đầu chương Welcome (`DocsPage.tsx`, trước `MarkdownContent`, chỉ hiện khi `chapter.slug === 'welcome'`), và card gọn ở cuối `TableOfContents.tsx` (cột phải) hiện ở **mọi trang** dùng `DocsLayout`, kể cả khi chương đó không có heading H2/H3 nào — `DocsLayout.tsx` không còn ẩn hẳn cột phải khi `headings.length === 0` nữa, `TableOfContents` tự xử lý phần nav heading rỗng bên trong. Dùng token theme-aware `accent-on-surface` (không dùng `accent-soft` — token đó cố định sáng, chỉ dành cho Landing, sẽ vỡ contrast ở dark mode của Docs). — file này được generate qua `scripts/generate-chapter-pdfs.mjs` (dùng Puppeteer render route ẩn `/print/docs/<slug>` — component `PrintChapterPage.tsx`, không sidebar/TOC/header/quiz, luôn tiếng Anh, luôn theme sáng bất kể `prefers-color-scheme` — rồi nén bằng `archiver`). `npm run generate:pdfs` là script CHẠY TAY RIÊNG (không nằm trong `npm run build`) — cần chạy lại và commit zip mới mỗi khi nội dung `.md` đổi. **Lịch sử quan trọng (2026-07-25):** từng thử gắn `npm run generate:pdfs` chạy tự động TRƯỚC bước `vite build` trong chính script `build`, nhưng phải revert ngay sau đó — môi trường build của Cloudflare Workers (kích hoạt qua git-integration mỗi lần push lên `main`) không hỗ trợ chạy headless Chromium thật (thiếu thư viện hệ thống/bị giới hạn sandbox), khiến build trên Cloudflare fail âm thầm ở MỌI lần push kể từ đó — production bị kẹt ở bản deploy cũ suốt một thời gian mà không ai nhận ra ngay. Bài học: `npm run build` phải luôn an toàn để chạy trong CI/CD của Cloudflare — không được thêm bước cần trình duyệt thật (Puppeteer/Playwright) vào đó. Danh sách slug trong script generate là literal array (không import `src/content/chapters/index.ts` vì file đó dùng `import.meta.glob`, chỉ chạy được trong Vite) — phải tự sửa tay nếu thêm/bớt/đổi thứ tự chương. File zip vẫn commit vào git (như `public/images/`) để có sẵn ngay cả khi ai đó chỉ chạy `npm run dev` mà chưa build lần nào.
- **LandingPage (redesign)**: đã chuyển hoàn toàn từ `docs/design-references/PRO192-Landing.dc.html` sang component thật ở `src/components/landing/` (`AnnouncementBar`, `LandingNav`, `HeroSection`, `CodeBlock` riêng cho hero — không phải `src/components/CodeBlock.tsx` dùng cho Docs, `ChapterGrid`, `SiteFooter`) + `src/pages/LandingPage.tsx` lắp ráp. Dữ liệu hiển thị 11 chương cho lưới này nằm ở `src/data/chapters.ts` (field `id/slug/name/tag/description`) — **khác** với `src/content/chapters/` (dữ liệu đầy đủ dùng cho `/docs`); `slug` ở 2 nơi khớp nhau theo thứ tự để card/CTA trỏ đúng route thật `/docs/<slug>`, nhưng đây là 2 nguồn dữ liệu riêng biệt, sửa 1 bên không tự động cập nhật bên kia.
